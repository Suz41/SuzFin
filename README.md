# 🍎 SuzFin

A modern, standalone Jellyfin theme.

---

## 🚀 Quick Install

Add this to your Jellyfin **Custom CSS code** field (**Dashboard** $\rightarrow$ **General** or **Display**):

```css
@import url("https://cdn.jsdelivr.net/gh/Suz41/SuzFin@main/theme.css");
```

Click **Save** and refresh (`Ctrl + Shift + R`).
