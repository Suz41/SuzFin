# 🍎 SuzFin

A refined, cinematic Jellyfin theme built on Abyss with comprehensive support and optimizations for **PC**, **Mobile**, and **Smart TVs (Samsung Tizen / Android TV)**.

---

## ✨ Features

- **Cinematic Detail Backdrop:** Immersive, dynamic movie backdrops with fine-tuned blur, saturation, and contrast.
- **Multi-Device Responsive:** Dedicated layouts tailored for Desktop PCs, Mobile phones (portrait & landscape), and Smart TVs.
- **Clean Card Overlays:** Distraction-free media cards with unobtrusive action controls.
- **Smart TV Performance Built-In:** Hardware-conscious transitions and optimizations to keep low-RAM devices (such as 32" Tizen TVs) fast and responsive.

---

## 🚀 Quick Install

Add the following to your Jellyfin **Custom CSS code** field:
- **Server-wide:** **Dashboard** $\rightarrow$ **General** / **Branding** $\rightarrow$ **Custom CSS**
- **User-specific:** **User Settings** $\rightarrow$ **Display** $\rightarrow$ **Custom CSS**

```css
@import url("https://cdn.jsdelivr.net/gh/Suz41/SuzFin@main/theme.css");
```

Click **Save** and refresh your browser (`Ctrl + Shift + R`) or reload your Jellyfin TV/mobile client.
